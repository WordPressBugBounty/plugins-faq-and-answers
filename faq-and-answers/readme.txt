### Why Awesome FAQ?

**Awesome FAQ** is a lightweight, user-friendly WordPress plugin that lets you create beautiful and responsive FAQ sections using **Gutenberg Blocks** or **shortcodes**. It's perfect for bloggers, business owners, online shops, portfolios, and anyone who needs a simple and elegant way to display frequently asked questions.

FAQ Schema (JSON-LD) is built right in. With one click, your FAQs are marked up with Google-recommended structured data – increasing the chances of rich results and "People Also Ask" snippets in search engines. No extra SEO plugin needed. An analytics dashboard also shows which questions get the most views, clicks, and engagement, so you can continuously improve your content.

The Pro version goes further with an AI-powered FAQ generator: draft product FAQs for WooCommerce using OpenAI (GPT-4o), Anthropic (Claude Sonnet), or the native WordPress 7.0 Connectors API, and generate Q&A content with custom layout prompts right inside the Block Editor.

### How to Use Awesome FAQ – Quick Start

**Using the Gutenberg Block:**

1. Open a page or post in the block editor.
2. Click the **Add Block** (+) button and search for **Awesome FAQ**.
3. Add the block, then choose a theme and set colors, icons, typography, and toggle options.
4. Add your questions and answers.
5. Publish – your FAQ section is live!

**Using a Shortcode:**

1. Go to **Awesome FAQ → Add New FAQ** in the dashboard.
2. Enter your questions and answers, assign categories if needed, and click **Publish**.
3. Copy the generated shortcode and paste it into any post, page, or widget.

**Using WooCommerce Product FAQs (Pro):**

1. Edit a WooCommerce product and scroll to the **Product FAQ — Awesome FAQ** box.
2. Check **Show FAQ Section on This Product**.
3. Write FAQs manually or click **Auto-Generate from Product** to draft them with AI.
4. Pick a theme, click **Update**, and configure global options at **WooCommerce → Settings → FAQ AI Settings**.

== Installation ==

**From your WordPress dashboard (recommended):**

1. Go to **Plugins → Add New**.
2. Search for **"Awesome FAQ"**.
3. Click **Install Now**, then **Activate**.
4. Add the **Awesome FAQ** block to any page, or create FAQs under **Awesome FAQ → Add New FAQ**.

**Manual installation:**

1. Download the Awesome FAQ plugin (`faq-and-answers.zip` file).
2. In your admin area, go to **Plugins → Add New** and click **Upload Plugin**.
3. Choose the ZIP file, click **Install Now**, then **Activate**.
4. Alternatively, upload the plugin folder to the `/wp-content/plugins/` directory and activate it through the **Plugins** menu.

== Frequently Asked Questions ==

= I don't know coding. Can I use the plugin? =
Yes. You don't need any coding knowledge to use the plugin – everything is configured visually.

= Does the plugin contain any ads? =
No, the plugin is 100% ad-free.

= How many FAQ areas can I create? =
There is no limit – you can create unlimited questions, answers, and FAQ sections.

= Does Awesome FAQ add FAQ schema for SEO? =
Yes. FAQ Schema (JSON-LD) is built in and fully compatible with Google Rich Results, increasing your chances of FAQ rich snippets and "People Also Ask" placements – no extra SEO plugin needed.

= Can I add FAQs to WooCommerce product pages? =
Yes, with the Pro version you can show FAQ sections on product pages, either in a dedicated product tab or below the product summary, and even auto-generate the FAQs with AI.

= Can I track how visitors use my FAQs? =
Yes. The analytics dashboard shows which questions get the most views, clicks, and engagement so you can improve your content.

= Which AI providers does the FAQ generator support? =
The Pro AI builder supports OpenAI (GPT-4o), Anthropic (Claude Sonnet), and the native WordPress 7.0 Connectors API, which runs a core-registered AI client with zero key setup.

= Where do I report security bugs found in this plugin? =
Please report security bugs found in the source code of the Awesome FAQ plugin through the Patchstack Vulnerability Disclosure Program. The Patchstack team will assist you with verification, CVE assignment, and notify the developers of this plugin.
